# yas-sdd — instruções para agentes

As instruções estão em [`CLAUDE.md`](./CLAUDE.md). Duas regras valem antes de
qualquer outra:

1. **Sem atribuição de IA** em commit, pull request ou issue — sem coautoria,
   sem "gerado com", sem assinatura de ferramenta.
2. **Nada direto na `main`.** Branch por assunto, Conventional Commits, pull
   request.
