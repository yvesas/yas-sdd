# yas-sdd

## O que é

Pack de skills em markdown para desenvolvimento guiado por especificação, com
uma constituição montada em camadas a partir de uma entrevista. Baseado no
GitHub Spec Kit, sem depender dele.

Para quem fez um produto com IA e quer construir o resto com ordem — gente
que pode nunca ter aberto um terminal.

## Objetivos

- Do zero a uma constituição escrita, sem instalar nada além das skills.
- Especificar, planejar e implementar uma feature sob essa constituição.
- Um estado de projeto que cabe numa tela.

## Fora de escopo

- Qualquer dependência de runtime para quem usa.
- Operar infraestrutura: criar conta, configurar plataforma, publicar.
- Descoberta de produto — isso é do `yas-canvas`.
- Tradução para outros idiomas.
